# Sources
- Labour force (employment, unemployment rate, participation, employment rate): Statistics Canada Table 14-10-0327-01, annual, both sexes, 15+, 1976-2025.
- GDP: Statistics Canada Table 36-10-0222-01 (expenditure-based, GDP at market prices; chained 2017 dollars and current prices), 1981-2024.
- Population: Statistics Canada Table 17-10-0005-01 (July 1 estimates), 1971-2026.
- CPI (all-items, 2002=100): Statistics Canada Table 18-10-0005-01. BC from 1979, Canada from 1914.
- Hourly wages: Statistics Canada Table 14-10-0340-01 (LFS), all employees, both sexes, 15+, 1997-2022.
- Debt 1969/70-2011/12: BC Ministry of Finance, Historical Provincial Debt Summary, Table A2.15 (open.canada.ca / BC Data Catalogue).
- Debt 2012/13-2018/19: BC Budget and Fiscal Plan 2019/20-2021/22, Tables A17, A19. Debt 2019/20-2025/26: BC Budget and Fiscal Plan 2026/27-2028/29, Tables A17, A19 (2025/26 is an updated forecast).
- Minimum wage (real, constant 2013 dollars), average hourly earnings and their ratio, 1983-2013: Statistics Canada, Perspectives on Labour and Income 75-006-X, 2014001, article 14035, Table A.1.
- Premiers and dates: Wikipedia, List of premiers of British Columbia (cross-check against elections.bc.ca).
